## Findings considered and rejected / deferred (do not re-audit)

- **`-maxrate 2M` caps quality at 1080x1920** (`chunker.py:591`): deliberate size/quality trade-off for phone-local storage; a `--quality` CLI knob is a nice-to-have, not a bug. Deferred.
- **Blur/pad math breaks for portrait sources** (`get_vertical_filter` assumes landscape input; negative `y_offset` if `scaled_height > height`): real but the pipeline's stated purpose is landscape TV episodes. Deferred; revisit if portrait sources appear.
- **`VideoModel.fromPath` splits on `/`** (`video_model.dart:18`): wrong on Windows desktop, fine on the Android target. Deferred until a desktop target is real.
- **`updateIndex` writes SharedPreferences on every page change**: cheap async write, no observed cost. Not worth doing.
- **`Consumer` rebuilds whole `PreloadPageView` on index change** (`video_feed_screen.dart:120`): it is also the mechanism that flips `autoPlay` on neighbors; a `Selector`-based split is premature. Not worth doing now.
- **`preloadPagesCount: 2` memory pressure** (up to ~5 live ExoPlayer instances): no crash evidence; measure before tuning. Deferred — revisit if OOMs are reported on low-end devices.
- **Feed sort interleaves shows alphabetically**: folded into plan 009 Step 2 (called out there for immediate S-effort fix as slice (a)).
- **`print()` instead of `debugPrint`, `Key? key` old style, unused `getVideosByEpisode`/`toJson`**: style-level; `getVideosByEpisode`/`toJson` are kept pending plan 009's verdict (they're the seed of the episode browser).
- **`detect_subtitle_stream` falls back to the first subtitle track regardless of language** (`chunker.py:173-182`): questionable default (may burn "Signs/Songs" of another language) but behavior is visible in the printed track info; make it a `--no-sub-fallback` flag if it ever bites. Deferred.
