# 📱 Binge-Scroller

Binge-Scroller is a two-part project designed to give you a TikTok/Reels-style endless vertical scrolling experience for your own local video files (like TV episodes or movies). 

Have you ever wanted to binge-watch a series but with the effortless vertical scrolling interface of modern social media apps? This project solves exactly that!

It consists of two main components:
1. **`video-chunker`**: A smart Python script that uses FFmpeg to cut long videos (like 40-minute episodes) into short, bite-sized vertical chunks. It features smart scene/silence detection to ensure cuts feel natural.
2. **`local_video_scroller`**: A sleek Flutter application that acts as the player. It scans your device for these chunks and plays them in an endless, preload-optimized vertical feed.

---

## 🛠️ Component 1: Video Chunker

The Video Chunker prepares your standard landscape videos for the vertical scroller. 

### Features:
- **Smart Chunking**: Detects scenes and silences to avoid cutting people off mid-sentence.
- **Vertical Formatting**: Can automatically convert landscape video to 9:16 vertical video using various methods (e.g., blurred background, center crop).
- **Hardware Acceleration**: Automatically detects and uses GPU encoding (NVENC, QuickSync, AMF) for ultra-fast processing.

### Prerequisites
- **Python 3.8+**
- **FFmpeg**: Must be installed and added to your system's PATH.
- Python dependencies: `pip install tqdm`

### How to Use the Chunker
Navigate to the `video-chunker` directory:
```bash
cd video-chunker
```

Run the `chunker.py` script on a folder containing your videos. 

**Recommended command (Instagram Reels / TikTok style with blurred background):**
```bash
python chunker.py /path/to/your/input_videos -d 90 --vertical blur --resolution 1080x1920 --strategy smart
```

**Fastest processing for testing:**
```bash
python chunker.py /path/to/your/input_videos -d 60 --vertical blur --resolution 720x1280 --strategy fixed -w 8
```

The processed chunks will be saved in a `Processed_Output` directory by default.

## 📱 Component 2: Local Video Scroller (Flutter App)

The mobile app is built with Flutter and uses a `PreloadPageView` to ensure smooth, buffer-free vertical scrolling between local video chunks.

### Prerequisites
- **Flutter SDK**: [Install Flutter](https://docs.flutter.dev/get-started/install) (version 3.10.3 or higher)
- **Android Studio** (or Android SDK tools) for building the APK.
- A physical Android device or emulator.

### Windows Android SDK Setup
If you see `No Android SDK found`, install Android Studio and make sure the Android SDK is installed. On most Windows setups, Flutter will find it automatically at:

`C:\Users\<your-user>\AppData\Local\Android\Sdk`

If your SDK is installed somewhere else, point Flutter at it with:

```bash
flutter config --android-sdk C:\path\to\Android\Sdk
```

You can also set the `ANDROID_HOME` environment variable to the same SDK path.

### How to Use the App
1. **Create the Folder**: On your Android device, create **`Internal storage → Movies → BrokeBinge`** (i.e. `/storage/emulated/0/Movies/BrokeBinge`).
2. **Transfer Videos**: Copy the output chunks generated by the `video-chunker` into this `Movies/BrokeBinge` folder.
3. **Grant Permissions**: The first time you open the app, it will ask for video/storage permissions so it can read the videos.

### Building the APK from Source
To build the app and install it on your device, follow these steps:

1. Navigate to the app directory:
   ```bash
   cd local_video_scroller
   ```
2. Get the required Flutter dependencies:
   ```bash
   flutter pub get
   ```
3. Build the release APK:
   ```bash
   flutter build apk --release
   ```
4. The generated APK will be located at:
   `build/app/outputs/flutter-apk/app-release.apk`
5. Install the APK to your connected device:
   ```bash
   flutter install
   ```
   *(Alternatively, copy the APK file to your phone and install it manually.)*

## 🚀 Workflow Summary

1. Take your episodes/movies and run them through `video-chunker`.
2. Connect your phone and move the output chunks into `Movies/BrokeBinge` on your phone's storage.
3. Build and install the `local_video_scroller` APK.
4. Open the app, grant permissions, and start scrolling!
